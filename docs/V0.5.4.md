## 源码与线上资源

代码来自原仓库 main 和云端 v0.5.4 源码树。核对时，云端源码树构建的首页及96个 assets 文件均与线上一致。后端仅合入功能差异。

公开代码保留严格环境配置、静态资源鉴权和不自动创建用户的约定。未照搬线上环境默认值、管理员种子或电子书认证豁免。

私有教程、上传资料、数据库、原始图像、MPA-Net 实验和组会汇报不在仓库内。团队卡片指向独立部署服务，主站构建不会自动部署其他项目。

## 构建与发布

```bash
npm ci
npm --prefix server ci
npm run build:h5 -- -p h5
```

构建成功只验证公开界面，不能证明生产资料齐全。发布到既有站点前，先在独立目录恢复所有者提供的私有资源，再检查：

```bash
python3 scripts/verify-web-release.py dist/build/h5 --manifest /path/to/private-static-baseline.json
```

清单格式：`[{"path":"static/example.txt","sha256":"64位SHA-256"}]`。清单来自完整部署备份，不在公开仓库中；默认位置 `release/static-baseline-v054.json` 被 Git 忽略。缺少清单时校验明确失败。

发布前备份现网，检查登录、备案、组会资料、电子教程、团队项目与API健康状态。不要仅依据干净构建覆盖生产目录。本次GitHub同步没有部署网站、改动线上账号或数据库。
