# R科研绘图电子书｜代码驱动重构版 V4 Preview

这是下一次网站更新前的内容开发预览版，不覆盖V3。

## 当前开放范围

- 在原有16节基础上继续补充第4—7章及第9章中可以可靠重建的图形。
- 页面显示的总节数由程序自动统计，不再手工写死。
- “已核验开放”是首批内容，“新增预览”需要继续逐节核对原书脚本。

## 设计原则

- 页面不读取或展示现有PNG结果图。
- 上方图形由浏览器根据固定章节数据实时绘制，下方提供对应R代码。
- 每节使用稳定种子；刷新和点击“重新绘制”都必须得到相同结果。
- 每节代码可下载为可运行的源文件：R章节使用 `.R`，MATLAB章节使用 `.m`。

## GitHub 方法重构

本轮不再让不同统计图共用手写 SVG 模板。浏览器端使用本地打包的 Apache ECharts 5.6.0（Apache-2.0）；三维科研图使用兼容的 ECharts-GL 2.0.9（BSD-3-Clause）。重点章节的 R 方法参照成熟开源项目，并在页面内逐节显示项目链接与许可证：

- GGally / `ggpairs`：散点矩阵。
- ggsurvfit：生存曲线、删失标记和风险表。
- ggridges：山脊密度图。
- ggdist：云雨图与不确定性分布。
- ComplexHeatmap：聚类热图方法。
- ComplexUpset：多集合交集图，替代集合较多时容易误读的维恩图。

网页只借鉴公开图形语法和数据结构，不嵌入 GitHub 项目的截图或图片资源。
