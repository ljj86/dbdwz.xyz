# 开源项目来源

本项目的浏览器预览与 R 方法设计参考以下公开项目。页面中不直接嵌入这些项目的截图。

| 项目 | 用途 | 许可证 | 地址 |
| --- | --- | --- | --- |
| Apache ECharts 5.6.0 | 浏览器 SVG/Canvas 图表引擎 | Apache-2.0 | https://github.com/apache/echarts |
| ECharts-GL 2.0.9 | WebGL 三维曲面、轨迹、散点和参数曲面 | BSD-3-Clause | https://github.com/ecomfe/echarts-gl |
| patchwork | 多图组合与对齐 | MIT | https://github.com/thomasp85/patchwork |
| ggforce | 局部放大与扩展几何 | MIT | https://github.com/thomasp85/ggforce |
| ggpubr | 统计检验和显著性标注 | GPL-2 | https://github.com/kassambara/ggpubr |
| ggbump | 排名凹凸图 | MIT | https://github.com/davidsjoberg/ggbump |
| GGally | 散点矩阵 `ggpairs()` | GPL-2 / GPL-3 | https://github.com/ggobi/ggally |
| ggsurvfit | 生存曲线与风险表 | MIT | https://github.com/pharmaverse/ggsurvfit |
| ggridges | 山脊密度图 | GPL-2 | https://github.com/wilkelab/ggridges |
| ggdist | 云雨图和分布不确定性 | GPL-3 | https://github.com/mjskay/ggdist |
| EnhancedVolcano | 火山图阈值、标签与连接线 | GPL-3 | https://github.com/kevinblighe/EnhancedVolcano |
| ComplexHeatmap | 热图、注释与聚类 | MIT | https://github.com/jokergoo/ComplexHeatmap |
| ComplexUpset | 多集合交集图 | MIT | https://github.com/krassowski/complex-upset |
| circlize | 圆形图、和弦图和 Circos 方法 | MIT | https://github.com/jokergoo/circlize |
| ggalluvial | 冲积图和多维分类流 | GPL-3 | https://github.com/corybrunson/ggalluvial |

第三方库版权归原作者所有。`vendor/echarts.min.js` 固定为与 ECharts-GL 2.x 兼容的 Apache ECharts 5.6.0。部署时应同时保留本说明、`vendor/LICENSE-echarts.txt`、`vendor/NOTICE-echarts.txt`、`vendor/LICENSE-echarts-gl.txt` 和 `vendor/NOTICE-echarts-gl.txt`。
